## Fase 3: datos clínicos estructurados

La carpeta [`fase3-clinica/`](fase3-clinica/) tiene la base de código para un futuro conversor y anonimizador offline de datos clínicos (diccionario preliminar, validación, k-anonimato). **Está bloqueada para datos reales** hasta tener la aprobación del comité de ética, el diccionario validado por un bioestadístico y la cita de semiología confirmada. Ver [`fase3-clinica/docs/PENDIENTES.md`](fase3-clinica/docs/PENDIENTES.md).
